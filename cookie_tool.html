X Cookie 生成工具

填入从浏览器获取的 auth_token 和 ct0，一键生成 cookies.json。纯本地运行，token 不会上传任何服务器。

1填写 Cookie 值

浏览器登录 x.com → 按 F12 → Application → Cookies → https://x.com → 找到 auth_token，复制它的 Value（约 40 位十六进制字符串）

同一个 Cookies 列表里找到 ct0，复制它的 Value（较长的字符串）

2生成结果

3配置到 GitHub Actions

  1. 复制上方生成的整段 JSON
  2. 打开仓库 zfselvia-ai/seo-signal-radar → Settings → Secrets and variables → Actions
  3. New repository secret，Name 填 X_COOKIES_JSON，Secret 粘贴 JSON
  4. 保存后，下次定时任务（每天 07:00 北京时间）会自动用此 cookie 抓取 Twitter

本地测试：把下载的 cookies.json 放到项目根目录，运行 python main.py daily，确认控制台无 [x] fetch aborted 报错。

cookie 会过期（几天到几周），失效后重新生成并更新 GitHub Secret 即可。
建议使用 X 小号，避免主账号被风控。
