Evidence · 1 source
Merj built 100 test pages plus live production pages and ran multiple agents repeatedly over six months. Average task success rose from roughly 30% (Nov 2025) to 60% (Mar 2026); canvas apps (~24→34%), icon-only buttons (~34→45%) and GDPR banners (~50→64%) stayed weakest. In a mislabeled-ARIA test, ChatGPT Agent in Atlas clicked Cancel first in 25 of 25 runs while Claude Computer Use and Perplexity Comet hit Save 25/25. Merj does not publish the dataset, calls the values approximate, and sells agent-interaction monitoring; results are version-specific and already months old.

Playbook: Worth Testing

Playbook: turning the plain-text brand label on product pages into a link to the brand PLP lifted PLP organic traffic +18% in a SearchPilot A/B test | 玩法：把商品页上的纯文本品牌名改成指向品牌品类页的链接，品类页自然流量 +18%（SearchPilot A/B 测试）P2Data-backed
为何重要 Why: 机制是全站一致的 PDP→品类页内链给爬虫更清晰的“商品归属集合”信号，等于用一处模板改动给品类页注入内链权重；成本极低，且商品页本身没有受损。
证据 Evidence: controlled SEO split test on one ecommerce site (SearchPilot case study, Demetria Spinrad)
影响 Affects: ecommerce
行动 Action: 在 PDP 模板里把品牌/品类文字改为指向对应 PLP 的链接，按页面桶做 50/50 分流测试 4 周以上，看 PLP 自然流量相对预测值的变化。
如何测试 Test: PDP 模板：品牌/品类名文本 → 链接到对应 PLP；对照组保持纯文本；跑 4–6 周，对比 PLP 自然点击/会话与预测基线。
衡量 Measure: 品牌/品类 PLP 的自然流量相对预测值的提升（SearchPilot 得到 +18%，95% 可信区间），且 PDP 不下降。
成本与风险 Effort: 低：一处模板改动；风险是内链稀释或 PDP 受影响（本案例未见），以及案例由卖测试工具的供应商发布。
Evidence · 1 source
SearchPilot ran a controlled split test on an unnamed ecommerce site: variant PDPs linked the brand name to the brand-level PLP, control PDPs kept plain text. Result: a predicted +18% organic traffic uplift to brand-level PLPs at a 95% credible interval, while PDP traffic itself was inconclusive (no harm detected). Not stated: number of pages, test duration, interval bounds, or whether more inbound links produce a bigger lift. SearchPilot sells the testing platform.

Lighthouse 13.5 adds an 'Agent Resource Discovery' audit checking robots.txt Agentmap, <link rel=ai-catalog> and /.well-known/ai-catalog.json | Lighthouse 13.5 新增“代理资源发现”审计，检查 robots.txt Agentmap、ai-catalog link 与 well-known 文件P3Confirmed

影响 Affects: all

Evidence · 1 source
Lighthouse 13.5.0 (Sep 18, 2026) adds an ard-schema audit grouped with llms.txt under agent discovery, in an experimental 'Agentic Browsing' category with a pass ratio rather than a 0–100 score. It looks for a pointer in robots.txt (Agentmap), a <link rel="ai-catalog"> or an HTTP Link header, falling back to /.well-known/ai-catalog.json, and validates the file against the ARD schema; no catalog means Not Applicable, schema errors fail. ARD is a proposal by authors from Google, Microsoft and Hugging Face; v0.91 renamed the file to ard.json, which 13.5 does not yet check. No ranking implication is stated.
