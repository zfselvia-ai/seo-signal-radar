## Playbook: Worth Testing

- **GBP 'Moved' feature recommended over direct address updates for cross-state relocations | 跨州迁移商家时，建议使用 Google 商家资料（GBP）的“已迁移”功能而非直接更新地址**  `P2` `Observed`
  - 为何重要 / Why: 直接在现有 GBP 上更新跨州地址可能导致在新地区的排名丢失。使用“已迁移”功能（创建新 Profile 并联系支持标记旧 Profile 已迁移）可以保留历史权重并安全过渡。
  - 证据 / Evidence: expert_analysis
  - 影响 / Affects: local
  - 行动 / Action: test Y
  - 详情 / Detail: Sterling Sky outlines a specific workflow for businesses moving across state lines: instead of updating the address on the existing GBP (which risks ranking loss in the new state), SEOs should create a new profile at the new address, then contact Google support to mark the old profile as 'moved' to the new one.
  - 如何测试 / Test: 对于需要跨州迁移的 GBP 商家，不要直接在后台修改地址。在目标新地址创建一个全新的 GBP 商家资料并完成验证。随后，联系 Google GBP 支持团队，申请将旧的商家资料标记为“已迁移（Moved）”至新的商家资料。
  - 衡量 / Measure: 成功将旧 GBP 的评价和历史权重转移至新 GBP，且不会出现直接修改地址时常见的排名骤降或账号挂起问题。
  - 成本与风险 / Effort: 中等工作量（需要与 Google 支持团队人工沟通申诉）。相比直接修改地址导致封号或排名丢失的风险，此方案风险极低。
