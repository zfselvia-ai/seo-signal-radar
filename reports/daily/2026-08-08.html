Playbook: Worth Testing

The 'Cats.txt' experiment debunks llms.txt as 'GEO Astrology' | 'Cats.txt' 实验戳穿 llms.txt 的 GEO 伪科学面纱P2Data-backed
为何重要 Why: 揭示了当前GEO领域对 `llms.txt` 的盲目崇拜，证明爬虫抓取并不等于LLM在实时生成中使用了该数据。
证据 Evidence: reproducible_experiment
影响 Affects: all
行动 Action: test LLM retrieval sources
如何测试 Test: 在网站根目录部署一个包含高度独特、虚构事实的自定义文本文件（如 `seo_test.txt`）。监控服务器日志中LLM爬虫的抓取情况。随后在ChatGPT/Claude中，使用包含该独特词汇的提示词进行提问，测试其在开启和关闭联网搜索（Web Search）时的回答，验证其是否真正读取并利用了该文件内容，而非仅仅将其作为普通网页索引或产生幻觉。
衡量 Measure: LLM在未联网搜索时，无法回答该虚构事实；仅在联网搜索并明确抓取该URL时才能正确回答，从而证实其并非通过特定txt协议直接读取。
成本与风险 Effort: 低成本：编写一个txt文件并部署需10分钟，使用LLM测试需10分钟。无技术风险。
Evidence · 2 sources
Mark Williams-Cook's experiment showed that creating a 'cats.txt' file with the same structure as 'llms.txt' passed all the same validation arguments (being crawled, indexed, and cited via hallucination), proving that LLMs do not use these files for real-time retrieval as claimed.
