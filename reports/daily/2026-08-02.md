## Playbook: Worth Testing

- **Use Link Density charts to audit editorial vs boilerplate inbound links | 使用链接密度图表审计编辑链接与样板链接**  `P2` `Data-backed`
  - 为何重要 / Why: 区分高质量的“编辑内容内链接”（Editorial Links）与页眉/页脚/目录等“样板链接”（Boilerplate/Footer Links）对评估外链真实权重至关重要。
  - 证据 / Evidence: Majestic's Link Density charts in the Context and Pages reports.
  - 影响 / Affects: all
  - 行动 / Action: test Y
  - 详情 / Detail: Majestic's Link Density charts visualize how links are distributed across the HTML structure of a page. This allows SEOs to instantly distinguish whether an inbound link is embedded within unique editorial content or grouped in high-density navigation blocks.
  - 如何测试 / Test: 1. 导出目标站点的前 100 个核心外链 URL。2. 导入 Majestic Context 报告，查看 Link Density 图表。3. 筛选出链接密度极高（>80%）的页面，这些通常是页脚或侧边栏群发链接。4. 重点保留链接密度低且位于内容核心区域的“编辑链接”，重新评估真实外链画像。
  - 衡量 / Measure: 识别并剔除低价值样板外链的比例，提升外链审计的精准度。
  - 成本与风险 / Effort: 低成本。需要 Majestic 账号，耗时约 1-2 小时。
